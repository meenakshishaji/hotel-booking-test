# Hotel Room Booking



## Stack
Plain HTML, CSS, and JavaScript. 

## How to run
1. Clone this repository.
2. Open `index.html` directly in any browser.
   (OR  use the VS Code "Live Server" extension .)

## Features
- Room list rendered from hardcoded sample data
- Check-in / check-out date pickers
- Validation:
  - Check-in date cannot be in the past
  - Check-out date must be after check-in date
  - Must select a room before seeing a price
- Shows number of nights and total price once valid dates + room are selected
- prevents selecting a room that's already booked for the chosen
  dates 
- filter room list by max guest count
